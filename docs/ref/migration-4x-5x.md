# Migration guide (4.x to 5.x)

There is no automatic or in-place upgrade from 4.x: 5.x is always a fresh installation (see
[Installation](getting-started/installation.md)), and there is no package downgrade or rollback.
The step-by-step procedure lives in the [migration guide](../guide/migration/README.md):

- [Overview of changes](../guide/migration/README.md#overview-of-changes) — what changed between
  4.x and 5.x: plugin structure, configuration file, index patterns, navigation paths.
- [Before you begin](../guide/migration/README.md#before-you-begin) — back up the 4.x dashboard
  files and export the custom saved objects.
- [Reports](../guide/migration/reports.md) — preserve the PDF reports generated by the 4.x plugin.
- [Custom dashboards and visualizations](../guide/migration/dashboards.md) — export, import, and
  adapt saved objects to the 5.x index patterns and field names.
- [Configuration migration](../guide/migration/configuration.md) — map every 4.x `wazuh.yml`
  setting to its 5.x equivalent.
- [Multi-manager environments](../guide/migration/multi-manager.md) — adapt deployments that used
  several Wazuh manager API connections.
- [Validate the 5.x deployment](../guide/migration/README.md#after-the-migration-validate-the-5x-deployment)
  and [Troubleshooting](../guide/migration/README.md#troubleshooting).

See also:

  components.
- [Requirements](getting-started/requirements.md) — 5.x system requirements.
- [Release notes](release-notes.md#breaking-changes) — breaking changes in 5.0.
